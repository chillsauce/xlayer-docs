# Pinax
[Pinax](https://pinax.network/ "Pinax") provides Firehose block streaming and Substreams parallel indexing for X Layer, alongside archive JSON-RPC. Pinax maintains the open source Firehose and Substreams projects alongside StreamingFast, and runs its own X Layer nodes.

Firehose streams full blocks over gRPC, including call traces, internal transfers and balance changes that a JSON-RPC node does not return. Substreams runs Rust modules in parallel on top of those blocks, writing results to PostgreSQL or ClickHouse, streaming them to a consumer, or feeding a Graph Node as a subgraph data source.

Create a key at [app.pinax.network](https://app.pinax.network/ "Pinax app") and see the [documentation](https://app.pinax.network/docs "Pinax documentation") for endpoints and authentication.

**Supported network**: 
- X Layer mainnet
